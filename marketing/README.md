# Marketing assets

Hand-made App Store artwork. Unlike `screenshots/` (generated by `scripts/take_screenshots.sh`
and git-ignored), nothing here can be regenerated, so final exports are versioned: the release
tag (`1.3`, `1.4`…) records which artwork shipped with each version.

```
marketing/
├── promo/
│   ├── product-page-header/<locale>/   Product page header
│   └── search-results/<locale>/        Search results creative
├── previews/<locale>/                  App Preview videos
└── source/                             Sketch files (Git LFS)
```

Locales match App Store Connect: `en` (English U.S.) and `es` (Spanish Mexico).
Name exports by aspect ratio, e.g. `promo/product-page-header/es/21x9.png`.

## Specifications

Source: [Creative assets specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications)
and [App Store asset best practices](https://developer.apple.com/app-store/asset-best-practices/) (checked 2026-10-17).

**Images must not have an alpha channel or transparency.**

### Product page header

| Ratio | Size (px) | Formats |
|---|---|---|
| 21:9 | 3840 × 1646 | .png, .jpg, .jpeg |
| 16:9 | 5244 × 2950 | .png |

Video: 21:9, 3840 × 1646, 30 or 60 fps, 5–30 s, .mov/.m4v/.mp4. Plays muted (viewers can
unmute) and loops.

### Search results

| Ratio | Size (px) | Formats |
|---|---|---|
| 3:2 | 1920 × 1280 to 3840 × 2560 | .png, .jpg, .jpeg |
| 16:9 | 5244 × 2950 | .png |

Video: 3:2, 1920 × 1280 to 3840 × 2560, 30 or 60 fps, 5–30 s, .mov/.m4v/.mp4. Always
muted, loops. Without this asset, search falls back to in-app events, app previews, then
screenshots.

### App Previews

Resize with `scripts/resize_videos.sh <folder>`. Check the current
[app preview specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/app-preview-specifications)
before exporting.

## Before uploading

Check size and alpha (the result must say `hasAlpha: no`):

```sh
sips -g pixelWidth -g pixelHeight -g hasAlpha marketing/promo/*/*/*.png
```

To remove alpha losslessly: open the PNG in Preview → File → Export → PNG, uncheck **Alpha**.
From the command line (goes through JPEG at maximum quality, so it is very slightly lossy):

```sh
sips -s format jpeg -s formatOptions 100 file.png --out /tmp/x.jpg && sips -s format png /tmp/x.jpg --out file.png
```

## Sources (Sketch) and videos

`.sketch`, `.mov`, `.mp4` and `.m4v` files under `marketing/` are stored with Git LFS
(see `.gitattributes`), so the repository doesn't grow with every revision. Set it up once
per machine **before** adding any of them:

```sh
brew install git-lfs
git lfs install
```

Keep one `.sketch` per asset family in `source/` (e.g. `source/promo.sketch` with an artboard
per placement, ratio and locale) and export artboards at 1× straight into the folders above.
